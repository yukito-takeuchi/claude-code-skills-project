# 提案資料作成スキル

CLAUDE.mdのコンテキスト（AIworkerの事業・自分のポジション）を踏まえ、tl;dvの文字起こしから提案資料テキスト＋スライド構成アウトラインを生成する。

## 自動化する範囲

```
tl;dv文字起こし貼り付け
  ↓ 【自動】提案資料テキスト生成（Google Docにコピペ用）
  ↓ 【自動】スライド構成アウトライン生成（Canva作業の叩き台）
  ↓ 【手動】Canvaで自社フォーマットに落とし込み・最終調整
```

※ pptx自動生成はしない（Canvaフォーマットが崩れるため、アウトライン止まりが現実的）

## 入力の受け方

- **`/proposal`（引数なし）**：以下のメッセージを表示して入力を促す
- **`/proposal 研修`** など案件種別あり：種別を確定した上で文字起こしを促す
- **文字起こしが貼られたら**：即座に解析・生成を開始する

引数なし・文字起こしなしの場合のメッセージ：
```
tl;dvの文字起こしを貼り付けてください。
案件種別（研修 / コンサル / 開発）がわかれば一緒に教えてもらえると精度が上がります。
不明な場合は文字起こしから推測します。
```

## AIworkerの案件種別

案件種別が不明な場合は、文字起こしの内容から以下の基準で推測する：

| 種別 | 内容 | 判断基準 |
|------|------|----------|
| **研修** | 社内向けAIリテラシー・活用研修 | 「社員に使わせたい」「研修」「教育」「学ばせたい」 |
| **コンサル** | AI導入戦略・業務改善提案 | 「何から始めれば」「どう活用すれば」「戦略を立てたい」 |
| **開発** | AIを活用したシステム・ツール開発 | 「作りたい」「自動化したい」「ツール」「システム」 |

## 出力フォーマット

### 冒頭ヘッダー

```
【提案資料骨子】
顧客名/会社名：（文字起こしから読み取れる場合のみ）
案件種別：研修 / コンサル / 開発（推測の場合は「推測：〇〇」と明記）
```

---

### 出力①：提案資料テキスト（Google Doc用）

#### 1. 顧客の課題
- 文字起こしから顧客の言葉ベースで課題を抽出する
- **顕在課題**（本人が認識している課題）と**潜在課題**（背景にある本質課題）を分けて整理する
- 顕在課題3点、潜在課題2点程度

#### 2. 提案内容・解決策
- AIworkerの該当サービスで提供できる解決策を具体的に書く
- 従来の対応（手作業）と今回の提案フローの対比で整理する
- 提案フローはステップ形式（3〜4ステップ）で記載

#### 3. 期待される効果
- 導入後に顧客が得られる変化・メリット（3点程度）
- 定量的な効果（時間削減・コスト削減・投資回収期間）があれば記載
- ROI試算：現状コスト vs AI導入後のコスト比較（数値は商談から抽出、なければ「要確認」）

#### 4. 次のアクション・見積もり感
- AIworker側と顧客側それぞれのアクション
- 料金プランの構成案（商談から読み取れる場合は具体的に、なければ2プラン構成で提案）
- 導入ロードマップ（1〜3ヶ月の段階的フェーズ）

---

### 出力②：スライド構成アウトライン（自社テンプレート14枚構成）

各スライドに「タイトル＋記載すべき内容の箇条書き」を出力する。

```
スライド1：表紙
- 顧客会社名・提案タイトル・日付・株式会社AIworker 代表取締役 杉本卓應

スライド2：こんな課題はありませんか？
- 顕在課題（文字起こしから抽出、3点程度）
- 潜在課題（顕在課題の背景にある本質課題、2点程度）

スライド3：現状の課題（インパクトスライド）
- 「解決策はただ１つ」→ キャッチコピー1行（例：業務をAIに置き換えること）

スライド4：ご提案内容（従来 vs 今回の提案フロー）
- 従来の対応（手作業の問題点）
- 今回の提案フロー（ステップ形式、3〜4ステップ）

スライド5：ご提案内容（専用システム名・キャッチコピー）
- システム/サービス名
- 「〇〇様専用 〜〜システム開発」的なキャッチコピー

スライド6：プロジェクトのゴール
- 実現する3点（箇条書き）

スライド7：ご提案内容（機能詳細）
- 主要機能を2〜3ブロックで整理（機能名＋サブ要素）

スライド8：ご提案内容（システム処理フロー）
- 処理レイヤーごとのフロー（4レイヤー程度）

スライド9〜10：ご提案内容（機能デモ・画面イメージ）
- 各機能の説明文・補足（デモ画像はCanvaで差し替え）

スライド11：提供支援の概要（導入ロードマップ）
- 1〜3ヶ月の段階的フェーズ（AIworker作業 / 顧客アクション / ゴール）

スライド12：料金プラン
- 文字起こしから読み取ったプラン数・内容に合わせて出力
- 言及なし → デフォルト2プラン構成（例：梅・竹）で提案
- 各プラン：対象テーマ・含まれるサービス・価格帯（言及あれば）

スライド13：ROI試算
- 現状コスト vs AI導入後のコスト比較
- 月間削減額・工数削減・投資回収期間（数値は商談から抽出、なければ「要確認」）

スライド14：クロージング
- or/or形式の比較（現状維持 or 今すぐ導入）で刺さる問いかけ
```

---

### 補足：ヒアリング不足の箇所

文字起こしから読み取れなかった情報・次回確認すべき点をリストアップする。

---

## 注意事項

- 出力は日本語
- 文字起こしにない情報は「要確認」と明記し、補完しない
- 顧客の課題は文字起こしの言葉ベースで整理する（解釈を加えすぎない）
- スライドはCanva手動作業の叩き台なので、骨子レベルで十分
- 提案内容はAIworkerの3サービス（研修・コンサル・開発）の範囲内で考える
- 担当者は代表・杉本卓應が提案者として明記する
