# AIキャッチアップスキル

CLAUDE.mdのコンテキスト（スキル・ゴール・業務内容）を踏まえ、AI系ツールの最新情報を収集・整理して業務活用につなげる。

## モード

引数の有無でモードを切り替える：

| 引数 | 動作 |
|------|------|
| なし | 「何のキャッチアップをしますか？」と聞く |
| トピック（例：`Claude Code Skills`） | 即検索・整理開始 |

## 引数なしの場合

以下のようにユーザーに確認する：

```
何のキャッチアップをしますか？

例：
- Claude Code（Skills / MCP / Agentモード）
- Cursor / Windsurf などのAIエディタ
- OpenAI / Gemini などの競合モデル
- その他（自由に入力）
```

## 引数ありの場合

トピックを即座にWebSearchで調査し、以下のフォーマットで出力する。

## 出力フォーマット

### 1. 最新アップデートのまとめ
- 直近のリリース・機能追加・変更点を箇条書きでまとめる
- 情報源（URLなど）を明示する

### 2. 自分の業務に使えそうな機能
CLAUDE.mdのコンテキストを踏まえ、以下の観点で絞り込む：
- 受託開発・実装作業への活用
- 提案資料作成・商談での活用
- AI活用スキル向上（Claude Code のポテンシャル最大化）

### 3. 今すぐ試すべきこと（1つだけ）
- 最も優先度が高いアクションを1つだけ提示
- 具体的なコマンドや手順があれば添える

## 調査方針

- WebSearchで最新情報を取得する
- 公式ドキュメント・リリースノート・技術ブログを優先する
- 1〜2週間以内の情報を中心にまとめる
- 情報が古い場合はその旨を明示する
