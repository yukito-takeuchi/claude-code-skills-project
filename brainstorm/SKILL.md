# 壁打ちスキル

CLAUDE.mdのコンテキスト（自分のポジション・ゴール・会社情報）を踏まえた上で、思考整理・やるべきこと提案を行う。

## モード

引数によってモードを切り替える：

| 引数 | モード | 用途 |
|------|--------|------|
| なし or テーマ | **通常** | その日のモヤモヤ・テーマを壁打ち |
| `週次` | **週次レビュー** | 今週の計画・振り返りを整理 |
| `振り返り` | **振り返り** | 先週やった/やれなかったことを整理 |
| `深掘り [テーマ]` | **深掘り** | 1つのテーマを徹底的に掘り下げる |

## 入力テンプレート

引数なし or テーマのみの場合、以下のテンプレートをユーザーに提示して入力を促す：

```
## 今の状況
- （例：仕事が落ち着いている、新しい案件が始まりそう）

## 興味あること
- （例：Claude Code のSkills作成、MCP連携）

## 課題・足りていないこと
- （例：AI活用がまだ30%、営業の知識が薄い）
```

- 箇条書きでOK、1〜3行でも十分
- 抽象的でもOK（整理はこちらがやる）
- 引数にテーマが含まれている場合はテンプレート提示をスキップして即開始

## 出力フォーマット

毎回以下の構成で出力する：

### 1. 状況の整理
入力内容を構造化して整理する。CLAUDE.mdのコンテキストと組み合わせて、現在地を明確にする。

### 2. 本質的な問い
「結局、何を決めたいのか」「何が解決されれば前に進めるか」を1〜2文で示す。

### 3. 選択肢と優先度
取りうる行動・方向性を3つ程度挙げ、優先度と理由を添える。CLAUDE.mdの優先度（AI活用 > 営業 > 集客）を考慮する。

### 4. 今日やること（1つだけ）
最も優先度が高く、今日中に実行可能なアクションを1つだけ提示する。具体的に書く。

## 注意事項

- 出力は日本語
- 難しく考えすぎない。ユーザーが「次の一手」を即決できるレベルに落とし込む
- CLAUDE.mdのゴール（AI活用 → 将来開業）を常に念頭に置いて提案する
