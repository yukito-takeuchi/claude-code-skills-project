# 壁打ちスキル

CLAUDE.mdのコンテキスト（自分のポジション・ゴール・会社情報）を踏まえた上で、思考整理・やるべきこと提案を行う。

## モード

引数によってモードを切り替える：

| 引数 | モード | 用途 |
|------|--------|------|
| なし or テーマ | **通常** | その日のモヤモヤ・テーマを壁打ち |
| `週次` | **週次レビュー** | 今週の計画・振り返りを整理 |
| `振り返り` | **振り返り** | 先週やった/やれなかったことを整理 |
| `深掘り [テーマ]` | **深掘り** | 1つのテーマを徹底的に掘り下げる |

## 入力テンプレート

引数なし or テーマのみの場合、以下のテンプレートをユーザーに提示して入力を促す：

```
## 今の状況
- （例：仕事が落ち着いている、新しい案件が始まりそう）

## 興味あること
- （例：Claude Code のSkills作成、MCP連携）

## 課題・足りていないこと
- （例：AI活用がまだ30%、営業の知識が薄い）
```

- 箇条書きでOK、1〜3行でも十分
- 抽象的でもOK（整理はこちらがやる）
- 引数にテーマが含まれている場合はテンプレート提示をスキップして即開始

## 出力フォーマット

毎回以下の構成で出力する：

### 1. 状況の整理
入力内容を構造化して整理する。CLAUDE.mdのコンテキストと組み合わせて、現在地を明確にする。

### 2. 本質的な問い
「結局、何を決めたいのか」「何が解決されれば前に進めるか」を1〜2文で示す。

### 3. 選択肢と優先度
取りうる行動・方向性を3つ程度挙げ、優先度と理由を添える。CLAUDE.mdの優先度（AI活用 > 営業 > 集客）を考慮する。

### 4. 今日やること（1つだけ）
最も優先度が高く、今日中に実行可能なアクションを1つだけ提示する。具体的に書く。

### 5. 成長アドバイス（週次）
ユーザーの入力内容に関係なく、毎回必ず出力する。週1回の実行を想定し、各カテゴリから複数提案する。

以下の逆算ロジックで考える：
```
稼げる状態・独立 → 市場価値の高いエンジニア → 今身につけるべきスキル
```

**4つのカテゴリから各2〜3個ずつ提案する：**

- **【AI活用】** Claude Skills / MCP / Agentモードなど、今最優先で伸ばすべき領域
- **【営業】** 独立に必須・今最も不足しているスキル。本・動画・実践方法を具体的に
- **【集客(マーケ)】** 将来の案件獲得に必要なSNS・コンテンツ・集客の知識
- **【開発】** 市場価値を高めるための技術・ツール・手法

各提案には以下を含める：
- 具体的なアクション（YouTubeの検索キーワード・書籍名・実践方法）
- なぜ今それが重要か（独立ゴールとの紐づけ）

やるかどうかはユーザーが選ぶ。提案は多めに出す。

**出力例：**
```
## 5. 成長アドバイス（週次）

【AI活用】
- Claude Skills を週1本作る：/skill-creator で「tl;dv → 提案資料」Skillを作成。作りながら覚えるのが最速
- MCP連携を試す：YouTubeで「Claude MCP Notion 連携」で検索。Notionと繋ぐと情報管理が激変する
- Agentモードを触る：公式ドキュメントのQuickstartを30分でやる

【営業】
- 『無敗営業』（高橋浩一）を読む：BtoB営業の基礎が体系的に学べる。商談同席の質が上がる
- YouTubeで「法人営業 コツ 初心者」で検索：杉本さんの商談を観察する前に基礎を入れておく
- 商談同席時にトーク構成をメモする：杉本さんの営業を言語化して自分のものにする

【集客(マーケ)】
- noteの集客戦略を学ぶ：YouTubeで「note 集客 方法」で検索。自社の集客を理解する
- 『USJを劇的に変えた、たった1つの考え方』を読む：マーケ思考の基礎を作る
- X(Twitter)でAI×開発の発信を週1回試す：将来の個人集客の準備

【開発】
- Next.js / TypeScript の最新動向をキャッチアップ：YouTubeで「Next.js 2025」で検索
- AIを使ったコード生成の精度を上げる：Claude Codeでの指示の出し方を最適化する実験
```

## 注意事項

- 出力は日本語
- 難しく考えすぎない。ユーザーが「次の一手」を即決できるレベルに落とし込む
- CLAUDE.mdのゴール（AI活用 → 将来開業）を常に念頭に置いて提案する
- 第5セクションは必ず出力する（ユーザーが言及しなくても）
